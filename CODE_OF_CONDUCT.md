# Code of conduct

## The short version

Be decent. Argue with the work, not with the person. This project exists because
families of crash victims could not read a public file, so the bar for how people
are treated here is not low.

## What is expected

Assume the other person is trying to get it right. Say what you mean plainly.
When you disagree, say what you would do instead. Accept that a maintainer may
decline a change and still be grateful you offered it.

When you report a fault, bring the evidence: the control number, the case, what
the page said, what the file says. A claim about the data that cannot be checked
is not yet an issue.

## What is not acceptable

Harassment of any kind. Insults, demeaning comments, or attacks on someone's
person, background, or identity rather than on their argument. Publishing
anyone's private information. Sustained disruption of a discussion. Unwelcome
sexual attention or imagery.

This applies in issues, pull requests, commit messages, code comments and any
other space where the project is being discussed.

## Aircraft accidents

This project touches records of events in which people were injured and killed.
Do not use them to make a joke, and do not use a case as ammunition in an
argument about anything else. Individual pilots, mechanics and crew named or
implied in a record are not fair game for comment here.

## Enforcement

Report a problem through GitHub's private vulnerability reporting on this
repository, which reaches the maintainer privately, or by opening an issue if it
is something that can be discussed in the open.

The maintainer will read it, decide, and say what was decided. Responses range
from a request to edit a comment, through removal of a comment, to a block from
the repository. Whoever reports a problem is not required to argue their case in
public.
