# What it comes down to

**The display face is wrong.** The original sets the standing sentence in
Instrument Serif at 34px. The rebuild falls back to Georgia. The font is already
requested by the page's own stylesheet link; it is not being asked for by name in
the rule that matters.

**The count inside the sentence is monospace, and rust.** IBM Plex Mono at
31.28px in rgb(184,67,31), set inside a 34px serif line. A figure in a different
face is doing something deliberate: it says this number is a measurement and not
a word. The rebuild sets it in the same serif as the sentence, so it reads as
part of the prose.

**The ink is a different colour.** rgb(29,29,31) throughout the original,
rgb(33,29,20) and rgb(38,34,29) in the rebuild. Near-black with a blue cast
against near-black with a brown one. Small on one element, visible across a page.

**The aside is two thirds the size it should be.** 21.08px in the original,
15px here, and it carries "1,757,682 set aside", which is the second half of the
sentence and not a footnote.

**The aim line is purple.** rgb(93,74,114) where the original has rust,
rgb(184,67,31). Rust is reserved in this design for a chosen selection; the aim
line is where the instrument speaks about what you are pointing at, so it is rust
too. Nothing else on the page should be purple.

**The hand line is missing.** Archivo 13px semibold in rgb(29,29,31): "Click an
airline or an airframe to follow it." It changes with the open rail and it is the
only instruction on the instrument.

**The margin is too pale and half the height.** rgb(95,88,79) in the original
against rgb(140,132,116) here, and 45px against 27, because a note is missing
from it.
