<div class="panel" id="p-method">
  <div class="scope"></div>
  <div class="card">
    <h2>Where this comes from</h2>
    <p>Operators and mechanics must report failures, malfunctions and defects to the FAA. Those Service Difficulty Reports are public. This holds every report the FAA published for <strong id="m-range"></strong>, <strong id="m-total"></strong> in total, taken from the yearly files at <span class="muted">external.apic4e.faa.gov/sdrs/retrieve/SDR-YYYY.csv</span>. There is no FAA API; the files are downloaded whole and rebuilt here.</p>
    <h2 style="margin-top:14px">What it cannot tell you</h2>
    <p>This is not an accident database and not a safety ranking. A high count can mean an old fleet, a thorough maintenance department, or simply a large airline. Nothing here is divided by fleet size or flying hours, because the FAA file does not contain either.</p>
    <p>A write-up is a defect that maintenance caught. That is usually the system working, not failing.</p>
    <h2 style="margin-top:14px">About the codes</h2>
    <p>Most coded fields are decoded from the FAA's own lookup tables, which the FAA publishes as a
    zip file on the SDRS front page. This site carries the edition dated July 2026, shipped with the
    code so you can check it. Run against all <span class="corpus-n"></span>reports, those tables resolve every code that
    actually occurs, with none left over.</p>
    <p>Four fields are not in that zip and come from elsewhere, named here rather than left to be
    discovered. Corrosion grades come from FAA Order 8300.12 and EASA IMRBPB IP 119. Operator
    designators come from two FAA lists merged: the December 2006 Air Carrier/Operator
    cross-reference, whose host has since been retired, and the current list of certificated 121 and
    135 operators. The old edition is kept on purpose, because a carrier that stopped filing before
    2006, TWA among them, appears in no list published today. FAA regions and district offices are
    compiled from FAA designations. Some historic district offices resolve in neither list and are
    shown as the raw code.</p>
    <p>An earlier version of this page decoded the letters from a third-party copy of the tables,
    checked against three codes in the FAA's field instructions. That copy was wrong in at least one
    place: it had <code>R</code> as engine flameout, where the FAA's own table has <code>R</code> as
    a partial loss of rpm or power and <code>X</code> as flameout. Checking three cells said nothing
    about the rest. The tables now come from the FAA directly.</p>
    <h2>What this tool promises</h2>
    <p>Cold start to a quotable sentence on your clipboard in six gestures: click a starter question,
    click the operator in the WHO rail, drag a range across WHEN, click Case sheet on a row, read
    the quote, click Copy all three. Before this rewrite the same task took about eighteen, ten of
    them keystrokes inside two date fields. Nothing ships here that lengthens it.</p>
    <p>One thing here is not decoded from the FAA's own tables: the corrosion grades, which are not
    in the FAA zip. Those definitions come from FAA Order 8300.12 and EASA IP 119 and are labelled as
    such wherever they appear. The four-letter operator designator is expanded from two FAA sources merged: the Air Carrier/Operator cross-reference, December 2006 edition, whose host has since been retired, and the current list of certificated 121 and 135 operators. <span class="opgap-resolved"></span> The rest are shown exactly as filed. Any name can be stale where a carrier has merged, been
    renamed, or kept filing under a legacy code, so check current ownership before you publish.</p>
    <h2 style="margin-top:14px">Before you publish</h2>
    <p>Open the original report through the FAA's own query page, check the tail number in the FAA registry, and put the finding to the airline. Read the write-up itself rather than the count: the mechanic's sentence is the evidence.</p>

function sameDayRuns(rows){
  const g={};
  (rows||[]).forEach(x=>{
    const t=(x.RegistryNNumber||"").trim(), d=(x.DifficultyDate||"").trim();
    if(!t||!d)return;
    const k=t+"|"+d;
    (g[k]=g[k]||{t:t,d:d,n:0}).n++;
  });
  const runs=Object.values(g).filter(r=>r.n>4).sort((a,b)=>b.n-a.n);
  if(!runs.length)return "";
  const one=r=>`<b>${num(r.n)}</b> of them on N${esc(r.t)} on ${esc(ukDate(r.d))}`;
  let body;
  if(runs.length===1){
    body=`${one(runs[0])}`;
  }else{
    const rest=runs.length-2;
    body=runs.slice(0,2).map(one).join("; ")+(rest>0?`; and ${rest} more like it`:"");
  }
  return `<div class="runnote">Some of what you see here is one inspection, not one
    fault each: ${body}. A mechanic writes up every finding separately, so a heavy
    check on a single aircraft fills a page. Count events, not rows.</div>`;
}
function showFreshness(){
  const box=document.getElementById("freshness"); if(!box)return;
  fetch("api/freshness").then(r=>r.json()).then(d=>{
    if(!d||!d.newest_report)return;
    const day=x=>new Date(x+"T00:00:00Z").toLocaleDateString("en-GB",
      {day:"numeric",month:"long",year:"numeric",timeZone:"UTC"});
    let t="Reports up to and including <b>"+day(d.newest_report)+"</b>";
    if(d.rows)t+=", "+d.rows.toLocaleString("en-GB")+" in total";
    if(d.refreshed_at){
      const r=new Date(d.refreshed_at);

        : r.toLocaleDateString("en-GB",{day:"numeric",month:"long",year:"numeric",timeZone:"UTC"});
      t+=". Checked against the FAA "+when+", three times a day";
    }
    box.innerHTML=t+".";
  }).catch(()=>{});
}

function opFull(o){const e=(CODES.operator||{})[String(o||"").trim()];return e?`${e.label} (${o})`:(o||"")}
const esc=s=>(s==null?"":String(s)).replace(/[&<>"']/g,c=>({"&":"&amp;","<":"&lt;",">":"&gt;",'"':"&quot;","'":"&#39;"}[c]));
function codeObj(grp,v){const e=CODES[grp]&&CODES[grp][String(v||"").trim()];
  return (e&&typeof e==="object")?e:(e?{label:e}:null)}
function code(grp,v){const e=codeObj(grp,v);return e?(e.short||e.label):(v||"")}
/* a code shown as its meaning, hoverable for the FAA's own wording, clickable to filter */
function cc(grp,v,field){
  const e=codeObj(grp,v); if(!v)return '<span class="absent">not recorded</span>';
  if(!e)return esc(v);
  const short=e.short||e.label;
  const on=field?` onclick="setFilter('${field}','${esc(v)}')"`:"";
  /* When the plain English and the FAA wording say the same thing there is nothing
     to explain, so the value keeps its click but loses the dotted underline and the
     hollow tooltip, and recedes. That leaves the exceptional values as the only dark
     text in these columns. */
  const bare=!e.note && String(e.faa||"").toUpperCase()===String(e.label).toUpperCase();
  /* A filed code is a fact, even when it says "None". Only an empty field is absent. */
  if(bare) return `<span class="c dull"${on}>${esc(short)}</span>`;
  const tip=[e.label,e.faa?"FAA wording: "+e.faa:"",e.note||""].filter(Boolean).join(". ");
  return `<span class="term c" data-fixed="${esc(short)}|${esc(tip)}"${on}>${esc(short)}</span>`;
}

/* Which panels narrow to the current filter, and which always answer for the whole
   corpus. Saying it out loud is the only thing that stops a reporter reading a
   corpus-wide number as an answer to the question they just asked. */
const FOLLOWS_FILTER=["p-search","p-patterns","p-found"];
function filterWords(){
  const out=[];
  for(const [k,v] of params()){
    if(k==="hero")continue;
    let shown=v;
    if(k==="operator")shown=opFull(v);
    else if(k==="ata")shown=ATA[v]||v;
    else if(k==="jasc")shown=(CODES.jasc&&CODES.jasc[v]&&CODES.jasc[v].label)||v;
    else if(k==="zone")shown=code("part_location",v);
    else if(["nature","discovered","stage","corrosion"].includes(k))shown=code(k,v);
    else if(k==="crew")shown=code("precaution",v);
    out.push((LABEL[k]||k)+": "+shown);
  }
  return esc(out.join(", "));
}
function scopeLine(id){
  const box=document.querySelector("#"+id+" .scope"); if(!box)return;
  const n=[...params().keys()].length;
  const shown=(LAST_TOTAL!=null)?LAST_TOTAL:(heroData&&heroData.total!=null?heroData.total:null);
  /* Search already states the count in its own bar; a second line would only repeat it */
  /* two tables with two different scopes cannot share one sentence */
  if(id==="p-search"||id==="p-aircraft"){box.className="scope";box.innerHTML="";return}
  if(FOLLOWS_FILTER.includes(id)){
    /* with nothing filtered this only repeats the hero, so it stays out of the way */
    box.className="scope follows";
    box.innerHTML=n
      ? `Showing <strong>your selection</strong>${shown!=null?`, ${num(shown)} reports`:""}.`
      : "";
  }else{
    box.className="scope whole"+(n?" warn":"");
    box.innerHTML=n
      ? `This view always answers for <strong>all ${num(TOTAL)} reports</strong>.
         It does not narrow to your current selection
         (${filterWords()}).`
      : `All ${num(TOTAL)} reports.`;
  }
}
/* Roving tabindex is per tablist, not per page. The page has four: the hero
   rail picker and the three view groups. Treating them as one group left every
   tab at -1, which took the whole strip out of the tab order. */
function rove(){
  document.querySelectorAll('[role="tablist"]').forEach(list=>{
    const tabs=[...list.querySelectorAll('[role="tab"]')];
    if(!tabs.length)return;
    const keep=tabs.find(x=>x.getAttribute("aria-selected")==="true")||tabs[0];
    tabs.forEach(x=>x.setAttribute("tabindex",x===keep?"0":"-1"));
  });
}

  document.querySelectorAll(".panel").forEach(x=>x.classList.toggle("on",x.id===id));

  if(id==="p-leads"){loadLeads();loadSpikes();} if(id==="p-defect")loadDefects();

const NO_RAIL={q:"the mechanic's words",make:"manufacturer",model:"model",part:"part name",

function syncControls(){
  /* a control holding a value carries a rust edge, so the two routes never disagree
     about what is set */
  FIELDS.forEach(k=>{
    const e=el(k); if(!e)return;
    e.classList.toggle("landed",!!(e.value&&e.value.trim()));
  });
  const box=el("hero"); if(!box)return;
  /* and every mark that IS the current value reads as taken, not as available */
  const p=params();
  box.querySelectorAll("[data-take]").forEach(n=>{
    const [kind,key]=n.dataset.take.split("|");
    const f={zone:"zone",operator:"operator",tail:"tail",crew:"crew"}[kind];
    n.classList.toggle("taken",!!(f&&p.get(f)===key));
  });
}

function chips(){
  const p=params(), out=[];
  for(const k in UNRESOLVED)
    out.push(`<span class="chip warn">${LABEL[k]||k}: ${esc(UNRESOLVED[k])}
      <em>&mdash; not a value in this data</em>
      <b onclick="delete UNRESOLVED['${k}'];chips();search(0)">&times;</b></span>`);
  for(const [k,v] of p){
    if(k in UNRESOLVED)continue;      /* a rejected value gets one chip, not two */
    let shown=v;
    if(k==="ata")shown=ATA[v]||v;
    if(k==="operator")shown=opFull(v);
    if(k==="jasc")shown=(CODES.jasc&&CODES.jasc[v]&&CODES.jasc[v].label)||v;
    ["nature","discovered","stage","condition","corrosion"].forEach(g=>{if(k===g)shown=code(g,v)});
    if(k==="crew")shown=code("precaution",v);
    if(k==="zone")shown=code("part_location",v);
    if(k==="cracked")shown="recorded"; if(k==="minhours")shown=Number(v).toLocaleString("en")+" hours";
    out.push(`<span class="chip">${LABEL[k]||k}: ${esc(shown)}<b onclick="setFilter('${k}','')">&times;</b></span>`);
  }
  el("chips").innerHTML=out.join("");
  const warn=el("unresolved");
  if(warn){
    const n=Object.keys(UNRESOLVED).length;
    warn.className=n?"scope whole warn":"scope";
    warn.innerHTML=n?`One value in this link is not in this data, so no search was run. There is no
      number on this page to quote.`:"";
  }
}

/* mark the words the reporter searched for, on text nodes only, never over HTML */
function markHits(){
  const q=(el("q")&&el("q").value||"").trim(); if(!q)return;
  const esc0=q.replace(/[.*+?^${}()|[\]\\]/g,"\\$&");
  document.querySelectorAll(".wu .txt").forEach(t=>{
    if(t.dataset.marked===q)return;      /* never mark the same text twice */
    t.dataset.marked=q;
    /* the phrase can run across a glossary span, so match on the flat text and map
       each hit back to the node it came from */
    const w=document.createTreeWalker(t,NodeFilter.SHOW_TEXT,{
      acceptNode:n=>n.parentElement&&n.parentElement.closest("mark")
        ?NodeFilter.FILTER_REJECT:NodeFilter.FILTER_ACCEPT});
    const nodes=[]; let flat="";
    while(w.nextNode()){const n=w.currentNode; nodes.push([n,flat.length]); flat+=n.nodeValue}
    const rx=new RegExp(esc0,"ig"); const hits=[]; let m;
    while((m=rx.exec(flat))!==null){hits.push([m.index,m.index+m[0].length]);
      if(m.index===rx.lastIndex)rx.lastIndex++}
    if(!hits.length)return;
    for(let i=nodes.length-1;i>=0;i--){
      const [n,start]=nodes[i], end=start+n.nodeValue.length;
      const local=hits.filter(([a,b])=>b>start&&a<end)
        .map(([a,b])=>[Math.max(a,start)-start,Math.min(b,end)-start])
        .sort((p,q2)=>p[0]-q2[0]);
      if(!local.length)continue;
      const frag=document.createDocumentFragment(); let last=0;
      local.forEach(([a,b])=>{
        if(a>last)frag.appendChild(document.createTextNode(n.nodeValue.slice(last,a)));
        const mk=document.createElement("mark"); mk.className="hit";
        mk.textContent=n.nodeValue.slice(a,b); frag.appendChild(mk); last=b;
      });
      if(last<n.nodeValue.length)frag.appendChild(document.createTextNode(n.nodeValue.slice(last)));
      n.parentNode.replaceChild(frag,n);
    }
  });
}

/* The corpus stops mid-month, so the first and last buckets of any window can be
   partial. Drawn plain they read as a crash or a boom that is only the download
   date. They are kept, counted and marked, never dropped. */
let RANGE={from:"",to:""};
function partialMonth(m){
  if(!m||m.length!==7)return false;
  const a=(el("from")&&el("from").value)||RANGE.from, b=(el("to")&&el("to").value)||RANGE.to;
  if(!a||!b)return false;
  /* the corpus itself stops mid-month, so its last bucket is partial whether or not
     the reporter set a date */
  const corpusEdge=(m===String(RANGE.to).slice(0,7)&&!isMonthEnd(RANGE.to))
                 ||(m===String(RANGE.from).slice(0,7)&&String(RANGE.from).slice(8)!=="01");
  return corpusEdge || (m===a.slice(0,7)&&a.slice(8)!=="01") || (m===b.slice(0,7)&&!isMonthEnd(b));
}
function isMonthEnd(d){
  const [y,mo,da]=d.split("-").map(Number);
  return da===new Date(y,mo,0).getDate();
}

function bars(target,items,keyf,valf,click,rawHtml,demote){
  /* "Other" holds three quarters of some fields. Scaled against it every real
     category becomes a stub, so the leader is clamped and marked as cut. */
  const vs=items.map(valf).sort((a,b)=>b-a);
  const runnerUp=(()=>{const second=items.filter(x=>valf(x)===vs[1])[0];
    return second?keyf(second):"the next"})();
  /* clamp a hair above the runner-up so the cut bar still reads as the longer one */
  const max=Math.max(1, (vs[1]&&vs[0]>3*vs[1])?vs[1]*1.12:vs[0]);
  const keep=demote?items.filter(i=>!demote(i)):items;
  const down=demote?items.filter(demote):[];
  el(target).innerHTML=[...keep,...(down.length?[{__divider:1}]:[]),...down].map(i=>{
    if(i.__divider)return `<div class="bardivider">Below this line: codes that record no finding, and
      the value you filtered on. Kept, because they are what the FAA received.</div>`;
    const k=keyf(i), part=(target==="trend")&&partialMonth(String(k));
    return `<div>
    <span class="k${click?" c":""}" title="${esc(String(k).replace(/<[^>]*>/g,""))}"
      ${click?`onclick="${click(i)}"`:""}><span class="kt">${rawHtml?k:esc(k)}</span>${part?' <span class="muted">part month</span>':""}</span>
    <span class="t"><span class="b${part?" part":""}${valf(i)>max?" over":""}"
      style="width:${Math.min(100,valf(i)/max*100).toFixed(2)}%"></span></span>

    ${valf(i)>max?`<span class="cut">axis cut here, ${(valf(i)/Math.max(1,vs[1]||1)).toFixed(1)}

}

let FACET_OPS=[];
function resolveOperator(txt){
  const t=txt.trim().toUpperCase();

  }

     the other pane holding a stale card */

const CLAUSE_ORDER=["q","jasc","ata","part","condition","zone","operator","make","model",
                    "tail","crew","nature","discovered","stage","corrosion","minhours",
                    "cracked","from","to"];
function clauseText(k,v){
  if(k==="q")return `where a mechanic wrote &ldquo;${esc(v)}&rdquo;`;
  if(k==="operator")return esc(opName(v)||v);
  if(k==="ata")return esc(ATA[v]||v);
  if(k==="jasc")return esc((CODES.jasc&&CODES.jasc[v]&&CODES.jasc[v].label)||v);
  if(k==="zone")return esc(code("part_location",v)).toLowerCase();
  if(k==="crew")return esc(code("precaution",v)).toLowerCase();
  if(k==="tail")return "N"+esc(v);
  if(k==="cracked")return "with cracking recorded";
  if(k==="minhours")return `${num(+v)} hours or more on the airframe`;
  if(k==="from"||k==="to")return "";
  if(["nature","discovered","stage","corrosion"].includes(k))return esc(code(k,v)).toLowerCase();
  return esc(v);
}
function periodClause(){
  const f=el("from")&&el("from").value, t=el("to")&&el("to").value;
  if(!f&&!t)return "";
  const MON=["","January","February","March","April","May","June","July","August",
             "September","October","November","December"];
  const pretty=d=>{const [y,m,dd]=d.split("-").map(Number);return `${dd} ${MON[m].slice(0,3)} ${y}`};
  if(f&&t&&f.slice(0,7)===t.slice(0,7)&&f.slice(8)==="01"){
    const [yy,mm]=[+f.slice(0,4),+f.slice(5,7)];
    const lastDay=new Date(yy,mm,0).getDate();
    /* only call it a month when the whole month is in the selection */
    if(+t.slice(8)===lastDay)return `${MON[mm]} ${yy}`;
    return `1 to ${+t.slice(8)} ${MON[mm]} ${yy}`;
  }
  if(f&&t)return `${pretty(f)} to ${pretty(t)}`;
  return f?`from ${pretty(f)}`:`up to ${pretty(t)}`;
}

function sentenceHTML(d){
  const p=params(), bits=[];
  for(const k of CLAUSE_ORDER){
    if(k==="from"||k==="to")continue;
    const v=p.get(k); if(!v)continue;
    bits.push(`<span class="clause" tabindex="0" data-drop="${k}"
      data-aim="drop-${k}">${clauseText(k,v)}</span>`);
  }
  const per=periodClause();
  if(per)bits.push(`<span class="clause" tabindex="0" data-drop="from|to"
    data-aim="drop-period">${esc(per)}</span>`);
  /* belt and braces: if the figures on hand were computed for a different
     selection, say so instead of pairing them with these words */
  if(d&&HERO_FOR!==null&&HERO_FOR!==params().toString())
    return `<b class="fig">&hellip;</b> counting ${bits.join(", ")}&hellip;`;
  const n=d?d.total:0, corpus=d?d.corpus:TOTAL;
  if(!bits.length)
    return `<b class="fig">${num(corpus)}</b> reports, everything the FAA has published to
            ${esc(prettyDate(RANGE.to))}.`;
  const aside=corpus-n;
  /* n + aside === corpus is true by construction, so it checked nothing. The real

  const sums=!(d&&LAST_TOTAL!=null&&d.total!==LAST_TOTAL);
  return `<b class="fig">${num(n)}</b> ${n===1?"report":"reports"}, ${bits.join(", ")}.
    <span class="aside">${num(aside)} set aside.</span>` +
    (sums?"":`<span class="broken">the count above and the rows below disagree: reload before you
      quote either</span>`);
}

/* A number on its own is a display, not a finding. Each rail states, in plain
   words, what its own figures amount to. Everything here is counted from the
   current selection, so it changes when the reporter narrows. */
/* A report reaches the FAA days to months after the event, so the newest months
   hold only part of what they will eventually hold. Reading their dip as a fall is
   the most available wrong story in this data. */
function settled(m){
  const cut=(heroData&&heroData.lag&&heroData.lag.settled_before)||null;
  if(!cut||!m||m.length!==7)return true;
  const [y,mo]=m.split("-").map(Number);
  const end=new Date(Date.UTC(y,mo,0));            /* last day of that month */
  return end<=new Date(cut+"T00:00:00Z");
}
function rate(n,days){
  if(!n||!days||n<30||days<60)return "";
  const per=days/n;
  if(per>=1.5)return `about one every ${Math.round(per)} days`;
  return `about ${(n/days).toFixed(1)} a day`;
}
const WORDS=["","one","two","three","four","five","six","seven","eight","nine","ten"];
const spell=n=>WORDS[n]||num(n);
/* The shorthand below is what the mechanic typed. This is the same report as the
   FAA itself files it: every part a lookup in their code tables, nothing inferred.
   "Not reported" and "Other" are dropped because they tell the reader nothing. */
function specLine(sp){
  if(!sp)return "";
  const dead=["","Other","Not reported","Unknown","None"];
  const norm=x=>String(x||"").toLowerCase().replace(/[^a-z]/g,"");
  /* the part name is often the system said again ("Tire" under "Tire"), which reads
     as two facts when it is one */
  const sys=sp.system, part=sp.part;
  const dup=part&&sys&&(norm(sys).includes(norm(part))||norm(part).includes(norm(sys)));
  const bits=[sp.aircraft,sys,dup?"":part,sp.condition,sp.found,sp.stage]
    .filter(x=>x&&!dead.includes(x));
  if(sp.date)bits.push(prettyDate(sp.date));
  if(!bits.length)return "";
  return `<div class="spec-decoded">${bits.map(esc).join(" &middot; ")}</div>`;
}

function reading(kind,d){
  const tot=d.total||0; if(!tot)return "";
  const days=(d.span&&d.span.days)||0;
  const pct=(a,b)=>b?(Math.round(a/b*1000)/10).toFixed(1):"0.0";
  let out="";
  if(kind==="when"){
    const all=(d.months||[]).filter(m=>!partialMonth(m.m));
    const full=all.filter(m=>settled(m.m));
    const young=all.length-full.length;
    if(full.length<2)return "";
    const hi=full.reduce((a,b)=>b.n>a.n?b:a), lo=full.reduce((a,b)=>b.n<a.n?b:a);
    out=`Between ${num(lo.n)} and ${num(hi.n)} reports in a settled month, `
       +`busiest in ${monthName(hi.m)}, quietest in ${monthName(lo.m)}.`;
    if(full.length>=24){
      const last=full.slice(-12), prev=full.slice(-24,-12);
      const av=a=>Math.round(a.reduce((s,x)=>s+x.n,0)/a.length);
      const a=av(last), bb=av(prev), diff=pct(Math.abs(a-bb),bb);
      out+=` The last twelve settled months average ${num(a)} a month against ${num(bb)} `
         +`for the twelve before, a difference of ${diff}%.`;
    }
    if(young){
      const lag=(d.lag&&d.lag.p95_days)||0;
      out+=` The ${young===1?"most recent month is":spell(young)+" most recent months are"} left out `
         +`of those figures: reports still arrive up to ${num(lag)} days after the event, `
         +`so ${young===1?"it holds":"they hold"} only part of what ${young===1?"it":"they"} will hold. `
         +`The dip at the right of the chart is the post arriving late, not fewer faults.`;
    }
  }
  if(kind==="where"){
    const zs=(d.zones||[]).slice().sort((a,b)=>b.n-a.n);
    if(!zs.length)return "";
    const zoned=zs.reduce((s,z)=>s+z.n,0);
    const blank=d.no_location||0, worded=d.other_location||0;
    /* This used to read "the others never say where", which was false: they nearly
       all say where, in words the diagram cannot place. Only the blank ones say
       nothing, and they are about one report in twenty-seven, not four fifths of the file. */
    out=`${zs[0].label} accounts for ${num(zs[0].n)} of the ${num(zoned)} reports written `
       +`in the FAA&rsquo;s numbered zones, or ${pct(zs[0].n,zoned)}%. Those numbers are what `
       +`this diagram can place, and they are ${pct(zoned,tot)}% of the selection.`;
    if(worded)out+=` Another ${num(worded)} do say where, in words such as FUSELAGE or `
       +`CABIN rather than a zone number, so the drawing cannot show them.`;
    if(blank)out+=` Only ${num(blank)}, ${pct(blank,tot)}%, give no location at all.`;
    /* Zonder deze zin leest de alinea als een reeks voorbehouden. De tekening is
       een steekproef, maar wel een die laat zien waar het meeste stukgaat. */
    out+=` It is a sample rather than the whole file, but it does give you a good `
       +`idea of where the trouble sits.`;
  }
  if(kind==="whose"){
    const ops=(d.operator_rows||[]), nOps=d.operators||0;
    if(ops.length&&nOps>ops.length){
      const top=ops.reduce((s,r)=>s+r.n,0);
      out=`${spell(ops.length)} operators file ${pct(top,tot)}% of what is here; `
         +`the other ${num(nOps-ops.length)} share the rest.`;
      out=out.charAt(0).toUpperCase()+out.slice(1);
    } else {
      out=`${num(nOps)} ${nOps===1?"operator files":"operators file"} everything here.`;
    }
    out+=` ${num(d.aircraft||0)} aircraft appear in all.`;
    const sw=(d.swarm||[])[0];
    if(sw&&sw.n>1)out+=` One of them, N${sw.t}, is written up ${num(sw.n)} times.`;
  }
  if(kind==="forced"){
    const cr=d.crew_reports||0;
    if(!cr)return `<p class="reading">No report in this selection records an action the `
      +`crew had to take. Everything here was found on the ground.</p>`;
    out=`${num(cr)} reports, ${pct(cr,tot)}% of this selection, record something the crew `
       +`had to do rather than something found on the ground.`;
    const top=(d.crew||[]).filter(x=>!["K","0","O"].includes(x.code))
      .slice().sort((a,b)=>b.n-a.n)[0];
    if(top){
      const r=rate(top.n,days);
      out+=` The commonest is ${top.label.toLowerCase()}, ${num(top.n)} times`+(r?`, ${r}.`:".");
    }
  }
  return out?`<p class="reading">${out}</p>`:"";
}
function railWhen(d,open){
  const ms=d.months||[]; if(!ms.length)return "";
  const cmax=Math.max(1,...ms.map(m=>m.all)), smax=Math.max(...ms.map(m=>m.n),0);
  const H=open?84:14;
  const cols=ms.map(m=>{
    const part=partialMonth(m.m)||!settled(m.m);
    const ch=(m.all/cmax)*H, sh=NARROWED?(m.n/cmax)*H:0;
    return `<span class="mo${part?" part":""}" style="height:${H}px"
      data-aim="month|${esc(m.m)}" tabindex="${open?0:-1}"
      role="${open?"button":"presentation"}"
      aria-label="${esc(monthName(m.m))}, ${num(m.n)} reports${
        partialMonth(m.m)?", a part month":(settled(m.m)?"":", still filling up")}">
      <i class="ghostb" style="height:${ch.toFixed(1)}px"></i>
      ${sh?`<i class="selb" style="height:${sh.toFixed(1)}px"></i>`:""}
      ${part?`<i class="parth" style="height:${ch.toFixed(1)}px"></i>`:""}</span>`;
  }).join("");
  let mag="";
  if(open&&smax&&smax<cmax*0.25){
    const f=(cmax*0.62)/smax;
    const pts=ms.map((m,i)=>`${(i*(1000/(ms.length-1))).toFixed(1)},${(H-(m.n*f/cmax)*H).toFixed(1)}`).join(" ");
    mag=`<svg class="mag" viewBox="0 0 1000 ${H}" preserveAspectRatio="none" aria-hidden="true">
      <polyline points="${pts}" fill="none" stroke="#c44b28" stroke-width="1.5"
        vector-effect="non-scaling-stroke"/></svg>
      <span class="magnote">selection &times;${f.toFixed(1)} to be visible</span>`;
  }
  const axis=open?`<div class="axis">${ms.map(m=>
    `<span>${m.m.slice(5)==="01"?m.m.slice(0,4):""}</span>`).join("")}</div>`:"";
  /* 7px a month plus the gap, so a long run scrolls rather than shrinking to nothing */
  const wide=open&&ms.length>72;
  const mw=wide?`--mw:${ms.length*9}px;`:"";
  const val=periodClause()||`${(d.months||[]).length} months`;
  return `<div class="rail ${open?"open":""}" data-rail="when"${open?"":' onclick="setHero(\'horizon\')"'}>${gutter(RAILS[0],esc(val,open))}
    <div class="track" style="${mw}"><div class="months">${cols}</div>${mag}${axis}
    ${wide?`<div class="whenhint">${num(ms.length)} months, so the strip scrolls sideways.
      It opens at the most recent.</div>`:""}</div>
    ${open?reading("when",d):""}</div>`;
}

function phZones(d){

  const by={}; zs.forEach(z=>by[z.code]=z);
  const grid=[["ZONE 800","ZONE 200","ZONE 100"],
              ["ZONE 500","ZONE 400","ZONE 600"],
              ["ZONE 300","ZONE 700","ZONE 900"]];
  const cell=c=>{const z=by[c]||{label:c,n:0};
    return `<button class="phcell" data-take="zone|${c}"
      style="--f:${(0.10+0.80*(z.n/mx)).toFixed(3)}">
      <span>${esc(z.label)}</span><b>${num(z.n)}</b></button>`};
  return `<div class="phkey" aria-hidden="true"></div>
    <div class="phmap">${grid.flat().map(cell).join("")}</div>
    <div class="phmap pads">
      <button class="phcell pad" data-aim="pad|nowhere"><span>no location given</span>
        <b>${num(d.no_location||0)}</b></button>
      <button class="phcell pad" data-aim="pad|outside"><span>place named in words, not as a zone</span>
        <b>${num(d.other_location||0)}</b></button></div>`;
}
function phLadder(rows,takeKind){
  const mx=Math.max(1,...rows.map(r=>r.n));

      <span class="pn2">${esc(r.label)}</span>
      <span class="pb"><i style="width:${(r.n/mx*100).toFixed(1)}%"></i></span>
      <b>${num(r.n)}</b></button>`).join("")}</div>`;
}

/* ---- the typed route to any mark -------------------------------------------
   Everything the pointer can reach, reachable by typing its name. This is the only
   practical route for voice control, switch access and 200% zoom, and it is also
   the fastest route to one of 900 airframes or 309 operators. */
function aimTargets(){
  const d=heroData; if(!d)return [];
  const out=[];
  (d.months||[]).forEach(m=>out.push({label:monthName(m.m),take:"month|"+m.m,n:m.n}));
  (d.zones||[]).forEach(z=>out.push({label:z.label,take:"zone|"+z.code,n:z.n}));
  (d.crew||[]).forEach(c=>out.push({label:c.label,take:"crew|"+c.code,n:c.n}));
  (d.operator_rows||[]).forEach(r=>out.push({label:opName(r.o),take:"operator|"+r.o,n:r.n}));
  (d.swarm||[]).forEach(a=>out.push({label:"N"+a.t,take:"tail|"+a.t,n:a.n}));
  return out;
}

/* The box accepts five different kinds of thing. Collapsing them into one text
   field hid that a month, a zone, an airline and a tail are structured filters with
   the FAA's own definitions behind them, and left "any word" looking like the only
   option. The list names the kind and the size before you commit to one. */
const KINDLAB={period:"MONTH OR YEAR",zone:"ZONE",operator:"AIRLINE",tail:"TAIL",
               jasc:"SYSTEM",q:"WORD IN THE WRITE-UPS"};
let SUG=[], SUGI=-1, sugTimer=null, sugSeq=0, LAST_WORD=null;
function sugClose(){
  const box=el("aimSug"); if(!box)return;
  box.hidden=true; box.innerHTML=""; SUG=[]; SUGI=-1;
  const i=el("iAimAt"); if(i)i.setAttribute("aria-expanded","false");
}
function sugPaint(){
  const box=el("aimSug"); if(!box)return;
  if(!SUG.length){sugClose();return}
  /* grouped under a heading per kind: a year must not be buried under three
     registrations that merely start with the same digits */
  let last=null;
  box.innerHTML=SUG.map((o,i)=>{
    const head=(o.kind!==last)?`<div class="sughead sk-${esc(o.kind)}">${
      esc(KINDLAB[o.kind]||o.kind)}</div>`:"";
    last=o.kind;
    return head+`<div class="sug${i===SUGI?" on":""}${o.n?"":" nought"}" role="option"
      aria-selected="${i===SUGI}" data-i="${i}" ${o.n?"":'aria-disabled="true"'}>
      <span class="sl">${esc(o.label)}</span>
      <span class="sw">${o.n?esc(o.what):"no report in this file"}</span>
      <b>${num(o.n)}</b></div>`;
  }).join("");
  box.hidden=false;
  el("iAimAt").setAttribute("aria-expanded","true");
}

async function sugFetch(v){
  const mine=++sugSeq;
  try{
    const k=(el("aimKind")&&el("aimKind").value)||"";
    if(!k){
      const rv=await(await fetch("api/vocab?q="+encodeURIComponent(v)+"&limit=10")).json();
      if(mine!==sugSeq)return;
      SUG=(rv.rows||[]).map(row=>({kind:"q",value:String(row.term||"").toLowerCase(),
        label:String(row.term||"").toLowerCase(),what:"a word in the write-ups",n:row.n||0}));
      LAST_WORD=null; SUGI=-1; sugPaint(); return;
    }
    const r=await(await fetch("api/resolve?q="+encodeURIComponent(v)
      +(k?"&kind="+encodeURIComponent(k):""))).json();
    if(mine!==sugSeq)return;                  /* an older keystroke, dropped */
    /* the word reading is deliberately not offered here: this box is for the
       categories the FAA defines. Free text has its own field below.
       Zero-count rows are dropped while browsing, because a suggestion list should
       not offer dead ends. But once a kind has been asked for by name, "that year
       holds no reports" is the answer, and hiding it leaves an empty box instead. */
    const kk=(el("aimKind")&&el("aimKind").value)||"";
    SUG=(r.readings||[]).filter(x=>x.kind!=="q"&&(x.n>0||kk));
    LAST_WORD=(r.readings||[]).find(x=>x.kind==="q")||null;
    SUGI=-1; sugPaint();
  }catch(e){ if(mine===sugSeq)sugClose(); }
}

async function aimAtGo(){
  const raw=(el("iAimAt")&&el("iAimAt").value||"").trim();
  if(!raw)return;
  if(!((el("aimKind")&&el("aimKind").value)||"")){ handOff(); return; }
  aim(`reading &ldquo;${esc(raw)}&rdquo;&hellip;`);
  let r;
  try{ r=await(await fetch("api/resolve?q="+encodeURIComponent(raw))).json(); }
  catch(e){ aim("could not check that word just now."); return; }
  /* a reading nothing matches is not a reading; the word itself always stays on the
     list, even at zero, because "no report says this" is an answer too */
  const opts=(r.readings||[]).filter(x=>x.kind!=="q"&&x.n>0);
  const word=(r.readings||[]).find(x=>x.kind==="q");
  const empties=(r.readings||[]).filter(x=>x.kind!=="q"&&!x.n);
  if(!opts.length&&empties.length){
    /* the shape is right and the category is real; the file simply holds nothing
       there. Saying "no such category" would have been false. */
    const e0=empties[0];
    aim(`${esc(e0.label)} is a valid ${esc(KINDLAB[e0.kind]||e0.kind).toLowerCase()},
      but this file holds no report for it. It runs from ${esc(prettyDate(RANGE.from))}
      to ${esc(prettyDate(RANGE.to))}.`);
    return;
  }
  if(!opts.length){
    /* it used to search the write-ups without being asked, which quietly turned a
       category question into a text one. It offers instead. */
    aim(`no month, zone, airline, tail or system is called &ldquo;${esc(raw)}&rdquo;.
      ${word&&word.n?`<span class="aimopts"><button class="ghost" onclick="handOff()">
        Search the write-ups for &ldquo;${esc(raw)}&rdquo; instead <b>${num(word.n)}</b>
        </button></span>`
      :`No mechanic wrote that word either.`}`);
    return;
  }
  if(opts.length===1){ takeReading(opts[0]); return; }
  /* more than one real reading: DELTA is an airline and a word a mechanic writes.
     Picking one silently is how the wrong number reaches print. */
  AIM_OPTS=opts;
  aim(`&ldquo;${esc(raw)}&rdquo; could mean more than one thing here. Which do you want?
    <span class="aimopts">${opts.map((o,i)=>
      `<button class="ghost" onclick="takeReading(AIM_OPTS[${i}])">
        ${esc(o.label)} <em>${esc(o.what)}</em> <b>${num(o.n)}</b></button>`).join("")}</span>`);
}
let AIM_OPTS=[];
/* the handover to free text: it fills the field that owns it, scrolls it into view
   and runs the search, so the reporter can see which box answered */
function handOff(){
  const raw=(el("iAimAt")&&el("iAimAt").value||"").trim(); if(!raw)return;
  sugClose(); el("iAimAt").value="";
  el("q").value=raw;
  show("p-search"); search(0); showChange();
  const f=el("q");
  f.scrollIntoView({behavior:"smooth",block:"center"});
  f.classList.add("flash"); setTimeout(()=>f.classList.remove("flash"),1400);
  aimHold(`searched the write-ups for &ldquo;${esc(raw)}&rdquo;, not a category.
    <button class="undoit" onclick="history.back();unaim()">undo</button>`);
}
function takeReading(o){
  sugClose();
  if(o.kind==="q"){ el("iAimAt").value=o.value; handOff(); return; }
  el("iAimAt").value="";
  if(o.kind==="period"){
    const v=o.value;
    /* A year in progress does not run to 31 December. Taking 2026 used to caption
       the selection "1 Jan 2026 to 31 Dec 2026" over a count that stopped at the
       newest report, promising four months of data that do not exist yet. Both
       ends are held inside the range the file actually covers. */
    let lo,hi;
    if(v.length===4){ lo=v+"-01-01"; hi=v+"-12-31"; }
    else{ const [y,mo]=v.split("-").map(Number);
          lo=`${v}-01`; hi=`${v}-${String(new Date(y,mo,0).getDate()).padStart(2,"0")}`; }
    if(RANGE&&RANGE.from&&RANGE.to){
      const clo=lo<RANGE.from?RANGE.from:lo, chi=hi>RANGE.to?RANGE.to:hi;
      /* Clamp only where the period and the file actually overlap. A period that
         lies wholly outside, December 2026 asked in August, would otherwise come
         back as "1 Dec 2026 to 20 Aug 2026": a range running backwards. Left as
         asked, it returns nothing and says so. */
      if(clo<=chi){ lo=clo; hi=chi; }
    }
    el("from").value=lo; el("to").value=hi;
    show("p-search"); search(0); showChange();
  } else {
    setFilter(o.kind==="tail"?"tail":o.kind, o.value);
  }
  aimHold(`took ${esc(o.label)}, ${esc(o.what)}, ${num(o.n)} reports.
    <button class="undoit" onclick="history.back();unaim()">undo</button>`);
}


/* ---- drag a period out of the timeline -------------------------------------
   The signature gesture of the instrument: the reporter takes a period by pulling
   it out of the months rather than filling in two date fields. Touch has no drag,
   so there it is tap-first, tap-last; the keyboard walks the caret and Shift
   extends. All three paths end in the same two values. */
let dragFrom=null;
function monthAt(ev,track){
  const ms=(heroData&&heroData.months)||[]; if(!ms.length)return null;
  const r=track.getBoundingClientRect();
  const x=Math.min(Math.max(ev.clientX-r.left,0),r.width-1);
  return ms[Math.min(ms.length-1,Math.floor(x/(r.width/ms.length)))].m;
}
function paintBracket(a,b){
  const box=el("hero"); if(!box)return;
  const lo=a<b?a:b, hi=a<b?b:a;
  box.querySelectorAll(".mo").forEach(n=>{
    const m=(n.dataset.aim||"").split("|")[1];
    n.classList.toggle("inband",!!m&&m>=lo&&m<=hi);
  });
  const n=((heroData&&heroData.months)||[]).filter(x=>x.m>=lo&&x.m<=hi)
    .reduce((s,x)=>s+x.n,0);
  aim(`${esc(monthName(lo))} to ${esc(monthName(hi))} &middot; ${num(n)} reports &middot; release to take it`);
}
function takePeriod(a,b){
  const lo=a<b?a:b, hi=a<b?b:a;
  const [y,mo]=hi.split("-").map(Number);
  const last=new Date(y,mo,0).getDate();
  el("from").value=`${lo}-01`; el("to").value=`${hi}-${String(last).padStart(2,"0")}`;
  show("p-search"); search(0); showChange();
  aimHold(`narrowed to ${esc(monthName(lo))}${lo===hi?"":" to "+esc(monthName(hi))}.
    <button class="undoit" onclick="history.back();unaim()">undo</button>`);
}
document.addEventListener("pointerdown",e=>{
  const track=e.target.closest&&e.target.closest(".rail.open[data-rail=when] .months");
  if(!track)return;
  e.preventDefault();
  dragFrom=monthAt(e,track);
  if(dragFrom)paintBracket(dragFrom,dragFrom);
  track.setPointerCapture&&track.setPointerCapture(e.pointerId);
});
document.addEventListener("pointermove",e=>{
  if(!dragFrom)return;
  const track=document.querySelector(".rail.open[data-rail=when] .months"); if(!track)return;
  const m=monthAt(e,track); if(m)paintBracket(dragFrom,m);
});
document.addEventListener("pointerup",e=>{
  if(!dragFrom)return;
  const track=document.querySelector(".rail.open[data-rail=when] .months");
  const m=track?monthAt(e,track):dragFrom;
  const a=dragFrom; dragFrom=null;
  takePeriod(a,m||a);
});

/* ---- aim and take: one grammar for every mark ----------------------------- */
function aimTextFor(spec){
  const d=heroData; if(!d)return "";
  const [kind,key]=spec.split("|");
  if(kind==="month"){
    const m=(d.months||[]).find(x=>x.m===key); if(!m)return "";
    return `${esc(monthName(key))} &middot; ${num(m.n)} reports &middot; click to narrow to this month`;
  }
  if(kind==="zone"){
    const z=(d.zones||[]).find(x=>x.code===key); if(!z)return "";
    const placed=(d.zones||[]).reduce((a,x)=>a+x.n,0);
    return `${esc(z.label)} &middot; ${num(z.n)} of ${num(placed)} placed findings &middot; click to narrow`;
  }
  if(kind==="pad"){
    const n=key==="nowhere"?d.no_location:d.other_location;
    return `${num(n)} reports ${key==="nowhere"?"say nothing about where on the aircraft it was":"describe the place in words rather than with an FAA zone number"}, so they cannot be drawn on the aircraft`;
  }
  if(kind==="operator")return `${esc(opName(key))} &middot; click to follow this operator`;
  if(kind==="tail")return `N${esc(key)} &middot; click to follow this one airframe`;
  if(kind==="crew"){
    const cx=(d.crew||[]).find(x=>x.code===key); if(!cx)return "";
    return `${esc(cx.label)} &middot; ${num(cx.n)} reports &middot; click to narrow`;
  }
  if(kind==="crewall")return `${num(d.crew_reports||0)} of ${num(d.total)} reports forced the crew to act`;
  if(kind==="more-ops")return `not ranked here; use the operator control below to reach any of the 309`;
  if(kind==="more-tails")return `not ranked here; type a tail number in the controls below`;
  if(kind.startsWith("drop-"))return `click to drop this constraint`;
  return "";
}
function takeFor(spec){

  const d=heroData;

  if(kind==="crew"){ const cx=(d.crew||[]).find(x=>x.code===key);
    takeFilter("crew",key,cx?cx.label:key); return }
}

const XCACHE=new Map(); let xTimer=null, xOver=false, xKey=null;
function xHide(force){ if(xOver&&!force)return; el("tip").style.display="none"; xKey=null; }
/* Anchored to the element, not the cursor: a panel that follows the mouse can never
   be reached, and one placed below mid-screen falls off the bottom. */
let xAnchor=null, xDid=null;
function xPlace(target){
  const t=el("tip"); const el0=target||xAnchor; if(!el0)return;
  const r=el0.getBoundingClientRect(), h=t.offsetHeight||340;
  t.style.left=Math.max(8,Math.min(r.right+12,window.innerWidth-(t.offsetWidth||352)-12))+"px";
  t.style.top=Math.max(8,Math.min(r.top,window.innerHeight-h-8))+"px";
}
function xRender(d){
  if(d.error){el("tip").innerHTML='<b>No explanation available</b>';return}
  const facts=(d.facts||[]).map(([k,v])=>`<div class="f"><span>${esc(k)}</span><b>${esc(v)}</b></div>`).join("");
  const list=(d.list||[]).length?`<div class="lt">${esc(d.list_title||"")}</div>`+
    d.list.map(i=>`<div class="f"><span>${esc(i.label)}</span><b>${Number(i.n).toLocaleString("en")}</b></div>`).join(""):"";
  let links="";
  if(d.kind==="tail"){
    const reg="N"+String(d.value).toUpperCase().replace(/^N/,"");
    links=`<div class="lk"><a target="_blank" rel="noopener"
      href="https://www.flightradar24.com/data/aircraft/${encodeURIComponent(reg.toLowerCase())}">This aircraft on Flightradar24</a>`+
      (isoDate(d.date)?`<a target="_blank" rel="noopener" href="https://www.flightradar24.com/${esc(isoDate(d.date))}/12:00">Flightradar24 playback, ${esc(d.date)}</a>`:"")+
      `<a target="_blank" rel="noopener" href="https://flightaware.com/live/flight/${encodeURIComponent(reg)}">FlightAware history</a>
      <div class="muted">Flightradar24 keeps only about a week of history on a free account, so an
      older date will need a paid plan or another archive.</div></div>`;
  }
  if(d.kind==="operator"){
    links=`<div class="lk"><a target="_blank" rel="noopener"
      href="https://www.perplexity.ai/search?q=${encodeURIComponent((d.title||"")+" airline FAA operator designator "+d.value+" current owner")}">Check who owns it now</a></div>`;
  }
  el("tip").innerHTML=`<button class="tipclose" aria-label="Close" onclick="xHide(true)">&times;</button>
    ${xDid?xDid():""}
    <b>${esc(d.title||"")}</b>
    ${d.subtitle?`<div class="sub">${d.subtitle}</div>`:""}
    ${facts}${list}${links}
    ${d.source?`<div class="src">${esc(d.source)}</div>`:""}`;
  xPlace();
}
async function xShow(spec,ev,didFn){
  const [kind,v,v2]=spec.split("|");
  if(!v)return;
  const key=spec; if(key===xKey&&el("tip").style.display==="block")return; xKey=key;
  xAnchor=ev; xDid=didFn||null; el("tip").style.display="block"; xPlace(ev);
  if(kind==="jasc"){
    const e=(CODES.jasc||{})[v]||{};
    xRender({kind:"jasc",value:v,title:e.label||v,
      subtitle:"JASC code "+esc(v)+", chapter "+esc(v.slice(0,2))+" "+esc(ATA[v.slice(0,2)]||""),
      source:e.faa||"",facts:[]});
    return;
  }
  if(XCACHE.has(key)){xRender(XCACHE.get(key));return}
  el("tip").innerHTML='<b>Looking it up.</b>';
  const u=`api/explain?kind=${encodeURIComponent(kind)}&v=${encodeURIComponent(v)}`+
          (kind==="aircraft"||kind==="part"?`&v2=${encodeURIComponent(v2||"")}`:"");
  try{
    const d=await(await fetch(u)).json();
    if(kind==="tail")d.date=v2||"";
    XCACHE.set(key,d);
    if(xKey===key)xRender(d);
  }catch(e){ el("tip").innerHTML='<b>Could not look that up.</b>'; }
}

/* Where to go to check this report against something other than this page. The FAA
   publishes no per-report address: its own search is a form that posts, so the
   control number has to be pasted in. Saying that is better than inventing a link
   that would 404. */
function isoDate(v){
  const p=String(v||"").split("/");
  return p.length===3?`${p[2]}-${String(p[0]).padStart(2,"0")}-${String(p[1]).padStart(2,"0")}`:"";
}
function sourceLinks(d){
  const reg=String(d.RegistryNNumber||"").toUpperCase().replace(/^N/,"");
  const ctrl=String(d.OperatorControlNumber||"");
  const iso=isoDate(d.DifficultyDate);
  const out=[];
  out.push(`<a target="_blank" rel="noopener" href="https://sdrs.faa.gov/Query.aspx">The FAA&rsquo;s own
    search</a>. It posts a form rather than answering an address, so paste the control number
    <b class="mono">${esc(ctrl)}</b> into its Operator Control Number box.`);
  if(reg){
    out.push(`<a target="_blank" rel="noopener"
      href="https://www.flightradar24.com/data/aircraft/n${encodeURIComponent(reg.toLowerCase())}"
      >N${esc(reg)} on Flightradar24</a>, to see what the aircraft has been doing since.`);
    out.push(`<a target="_blank" rel="noopener"
      href="https://flightaware.com/live/flight/N${encodeURIComponent(reg)}">N${esc(reg)} on FlightAware</a>.`);
    if(iso)out.push(`<a target="_blank" rel="noopener"
      href="https://www.flightradar24.com/${esc(iso)}/12:00">Flightradar24 playback for ${esc(prettyDate(iso))}</a>.
      Free accounts reach back about a week, so an older day needs a paid plan.`);
    out.push(`<a target="_blank" rel="noopener"
      href="https://registry.faa.gov/AircraftInquiry/Search/NNumberResult?nNumberTxt=${encodeURIComponent(reg)}"
      >Who owns N${esc(reg)}</a>, in the FAA registry.`);
  }
  return `<ul class="srclinks">${out.map(x=>`<li>${x}</li>`).join("")}</ul>`;
}

    .filter(n=>n!==wrap&&!n.contains(wrap))

    if(e.key!=="Tab")return;

      .filter(x=>x.offsetParent!==null);

    if(e.shiftKey&&document.activeElement===first){e.preventDefault();last.focus()}
    else if(!e.shiftKey&&document.activeElement===last){e.preventDefault();first.focus()}
  };
  wrap.addEventListener("keydown",caseTrap);
}

    btn.textContent="copied"; setTimeout(()=>{btn.textContent=old},1500);
  }).catch(()=>{
    btn.textContent="copy failed, select the text"; setTimeout(()=>{btn.textContent=old},2600);
  });
}
