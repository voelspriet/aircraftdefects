# The diagnosis, which your last run found and did not act on

The page has its own writer for this element:

    renderCount(d)     composes the sentence from the returned selection and
                       writes it into #count
    renderOnPurpose()  writes the unfiltered sentence when nothing is filtered
    sdSearch(off)      calls one or the other on every load and every filter change

Your block's seatCount() also writes #count, and it runs from a MutationObserver,
so it fires *after* the page has written the true sentence and replaces it with
the seeded one. The seed was added to fix the phone, where the page never creates
#count at all.

So the seed has to be the fallback and never the last word. Write into #count only
when it is empty, and make sure your own observer does not treat the page's write
as a reason to write again. If you cannot tell an empty element from a written one
at the moment your observer fires, mark your own seed and refuse to replace text
you did not seed.
